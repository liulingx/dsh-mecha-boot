# dsh-mecha-boot

DeepSeek Harness 机体主题。每次启动先放一段约 15 秒、带配音和字幕的开场：身份确认 → 神经连接 → 机体和领航员 DeepSeek（女仆鲸娘）的线稿一笔一笔描出来 → 上色 → “知难而进——出击”画面点亮 → 一道扫描线扫进桌面。点击或按 Esc 跳过。

桌面（深色主题下）整体换皮：女仆鲸娘和机体分站两边的壁纸、斜切的装甲面板、电光蓝配色、红色发送键。第一次播放会把外观切到深色一次；想换回浅色在 设置 → 通用 → 外观。

- 安装：插件页 → 添加插件 → 填 `https://github.com/liulingx/dsh-mecha-boot` → 安装 → 立即启用 → 重开 DeepSeek
- 连不上 GitHub 时：用交付包里的 `dsh-mecha-boot` 文件夹，在“添加插件”里填它的完整路径（文件夹装完别删）
- 卸载：插件页 → 本插件 → 卸载
- 重看开场：开发者工具里输入 `__DSH_MECHA_BOOT__.play()`

机体为原创高达风格机甲（AI 生成）；鲸娘形象参考网上流传的 DeepSeek 娘同人图。仅供私人使用，不要发布或商用。
